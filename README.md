# oni-assets-probes

3D models of probe modules for [ONI](https://github.com/kafeg/oni), consumed as a Git
submodule at `public/assets/models/probes/`. Stored with Git LFS.

Modules are CubeSat form factors on a 100 × 113.5 mm grid. Each GLB is authored to real
dimensions and normalized on load by the game — see `modules/README.md` for the
Fusion 360 → Blender → GLB pipeline and the orientation convention.
